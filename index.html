📚 About This Project

This interactive demonstration showcases fundamental JavaScript concepts through 15 comprehensive exercises. All code execution and output can be viewed in your browser's developer console, providing real-time insights into JavaScript programming fundamentals.

🔍 How to View the Output

  1. Open Developer Console
    • Press F12 on your keyboard, OR
    • Right-click anywhere → Inspect → Console tab
    • Windows/Linux: Ctrl + Shift + J
    • Mac: Cmd + Option + J
  2. View Exercise Output
    • Scroll through the console to see all 15 exercises
    • Each exercise is clearly labeled with its number and topic
